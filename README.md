# Postcard Perfect

Build a mobile-first app that lets users create digital postcards. Users can snap or upload a photo, choose a postcard template, add text in handwriting style fonts or draw directly for real handwriting, place stickers, and attach a short voice clip. Then allow sharing via a link and offer a printable version. The flow should be create, customize, send.
